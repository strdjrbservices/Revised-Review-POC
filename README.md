# Revised-Review-POC

Appraisal Quality Control (QC) and Revision Verification System.

## Features
- XML structure and addenda difference comparison
- Order form field matching
- Rejection reason verification
- Compliance and reviewer sign-off workflow
- Report export and audit logging

## Setup and Running

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run migrations**:
   ```bash
   python manage.py migrate
   ```

3. **Start the development server**:
   ```bash
   python manage.py runserver
   ```
